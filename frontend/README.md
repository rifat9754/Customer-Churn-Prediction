# Customer Churn Prediction - Streamlit Frontend

A Streamlit dashboard for the churn prediction project (XGBoost model served through FastAPI).

## Project layout

```text
project-root/
├── api/
│   └── main.py              # FastAPI backend
├── frontend/
│   ├── app.py               # Streamlit app
│   └── requirements.txt
└── .streamlit/
    └── config.toml          # Light theme (see below)
```

## Installation

Install dependencies from the project root:

```bash
python -m pip install -r frontend/requirements.txt
```

## Running the app

Start FastAPI in terminal 1:

```bash
uvicorn api.main:app --reload
```

Start Streamlit from the project root in terminal 2:

```bash
python -m streamlit run frontend/app.py
```

Open http://localhost:8501.

> Always start Streamlit from the project root so that `.streamlit/config.toml` is picked up.

## Configuration

The FastAPI base URL defaults to `http://127.0.0.1:8000`. To change it:

- set the `API_BASE_URL` environment variable before starting Streamlit, or
- edit **FastAPI Base URL** in the sidebar and click **Check API connection**.

## API contract

| Endpoint   | Method | Purpose                              |
|------------|--------|--------------------------------------|
| `/health`  | GET    | Used by the sidebar connection check |
| `/predict` | POST   | Returns the churn prediction         |

The prediction form sends `POST /predict` with:

```json
{"features": { "...19 original customer fields..." }}
```

The response should contain a churn probability (`churn_probability`, `probability` or `churn_prob`) and may contain `prediction`, `threshold` and `model`. The default decision threshold is `0.536`.

## Theme / display notes

The app uses a fixed light theme. This is set in two places:

- `.streamlit/config.toml` tells Streamlit to use the light base theme.
- The CSS in `frontend/app.py` and the Plotly styling make text, inputs and charts readable even if your browser or OS is in dark mode.

If text ever looks invisible, hard-refresh the browser (Ctrl+Shift+R) and restart Streamlit.

## Pages

- **Overview**: dataset summary and recorded test metrics.
- **Churn Prediction**: form for the 19 original features; engineered features are generated by the API.
- **Model Analytics**: held-out test metrics and confusion matrix.

> Overview and Model Analytics show recorded metrics, not live data from a customer database.
